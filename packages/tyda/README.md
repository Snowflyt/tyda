# Tyda

A composable type-level programming toolkit for TypeScript, with a focus on type-safe functional programming.

This is an early development preview. It currently bundles [`@tyda/core`](https://www.npmjs.com/package/@tyda/core), [`@tyda/typeclass`](https://www.npmjs.com/package/@tyda/typeclass), [`@tyda/array`](https://www.npmjs.com/package/@tyda/array), [`@tyda/bigint`](https://www.npmjs.com/package/@tyda/bigint), [`@tyda/boolean`](https://www.npmjs.com/package/@tyda/boolean), [`@tyda/number`](https://www.npmjs.com/package/@tyda/number) and [`@tyda/string`](https://www.npmjs.com/package/@tyda/string). Expect breaking changes.

See [the repository](https://github.com/Snowflyt/tyda) for more information.
